# ML Learning Journey

A public record of my machine learning learning path, covering foundations, classical machine learning, deep learning, computer vision, NLP basics, and MLOps fundamentals.

This repo is designed to show steady, structured progress rather than random notebook work. As I move through each section, I will document core concepts, worked examples, implementation notes, and small projects that demonstrate understanding.

## Why this repo exists

I want a clear and disciplined way to learn machine learning from first principles through to practical deployment. The aim is not just to train models, but to understand the full workflow:

- framing a problem
- preparing and exploring data
- building and evaluating models
- improving performance
- communicating results
- packaging and deploying models

## What this repo covers

### 01 Foundations
Core ML concepts, the ML lifecycle, types of learning, training vs inference, overfitting, underfitting, leakage, bias and variance.

### 02 Python for ML
The Python tools and patterns most useful for machine learning workflows.

### 03 NumPy
Arrays, vectorisation, indexing, broadcasting, and numerical computing basics.

### 04 pandas
Loading, cleaning, joining, filtering, grouping, and preparing data.

### 05 Data Cleaning and Preprocessing
Missing values, scaling, encoding, feature preparation, and data pipelines.

### 06 EDA and Visualisation
Exploratory analysis, distributions, correlations, outliers, and charting.

### 07 Supervised Learning
Regression, classification, tree based models, ensembles, and model comparison.

### 08 Model Evaluation
Train test split, cross validation, metrics, confusion matrices, ROC AUC, RMSE, and error analysis.

### 09 Feature Engineering
Creating, selecting, and refining features to improve model performance.

### 10 scikit learn Projects
End to end classical ML projects with clear problem framing and evaluation.

### 11 Deep Learning
Neural networks, training workflows, and practical deep learning fundamentals.

### 12 Computer Vision
Image based learning, CNN fundamentals, transfer learning, and object detection.

### 13 NLP Basics
Text preprocessing, embeddings, transformers overview, and basic NLP workflows.

### 14 MLOps Basics
Model packaging, APIs, Docker, experiment tracking, and serving fundamentals.

### 15 Capstone Projects
Larger end to end projects that combine technical implementation with clear communication.

### notes
Reference notes, quick summaries, revision material, and useful links.
